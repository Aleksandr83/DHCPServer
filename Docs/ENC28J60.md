# ENC28J60 — Ethernet Module Wiring

## Hardware

- **MCU:** ESP32-WROOM-32 (ESP32-D0WDQ6)
- **Ethernet:** ENC28J60 (SPI → Ethernet)
- **Note:** WiFi не используется, всё подключение — через Ethernet.

## Wiring Diagram

| ENC28J60 | → | ESP32 (Dx) | GPIO |
|----------|---|------------|------|
| **VCC**  | → | **3.3V**   | —    |
| **GND**  | → | **GND**    | —    |
| **SCK**  | → | **D18**    | GPIO18 |
| **MOSI (SI)** | → | **D23**    | GPIO23 |
| **MISO (SO)** | → | **D19**    | GPIO19 |
| **CS**   | → | **D5**     | GPIO5  |
| **INT**  | → | **D4**     | GPIO4  |
| **RST**  | → | **D16**    | GPIO16 |

## Pinout

```

┌─────────┐                   ┌──────────┐
│ D4      ├───────────────────┤ INT      │
│ D5      ├───────────────────┤ CS       │
│ D16     ├───────────────────┤ RST      │
│ D18     ├───────────────────┤ SCK      │
│ D19     ├───────────────────┤ MISO(SO) │
│ D23     ├───────────────────┤ MOSI(SI) │
│ 3.3V    ├───────────────────┤ VCC      │
│ GND     ├───────────────────┤ GND      │
└─────────┘                   └──────────┘
```

## ESP-IDF Configuration

GPIO mapping for `esp_eth`:

```c
// SPI host
spi_device_handle_t spi_handle;
spi_bus_config_t bus_cfg = {
    .mosi_io_num = 23,
    .miso_io_num = 19,
    .sclk_io_num = 18,
    .quadwp_io_num = -1,
    .quadhd_io_num = -1,
};

// ENC28J60 config
eth_enc28j60_config_t enc28j60_config = ETH_ENC28J60_DEFAULT_CONFIG(5 /* CS */);
eth_mac_config_t mac_config = ETH_MAC_DEFAULT_CONFIG();
eth_phy_config_t phy_config = ETH_PHY_DEFAULT_CONFIG();
phy_config.reset_gpio_num = 16;  // RST
phy_config.phy_addr = 0;
phy_config.reset_timeout_ms = 100;
```
