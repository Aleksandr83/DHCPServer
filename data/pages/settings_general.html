General

The name this device answers to on the network: 1 to 63 letters, digits or hyphens. The default is DhcpServer.

Publish the name in the local network

The device answers to its host name and to <host name>.local through its own DNS, and publishes <host name>.local over mDNS.

Write the device events to Device.log

The journal keeps the device's own events: the start with the firmware version, why the previous run ended (a panic, a watchdog, a plain restart), a restart asked for from the interface or the console, an imported backup and a factory reset. It is /fat/logs/Device.log; a full file is archived to the card as log/Archive/Device/<dates>/Device.log.
