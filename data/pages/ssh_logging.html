SSH Logging

Log to file

Sessions, refused passwords and refusals by the subnet filter go to /fat/logs/SSH.log; a full file is archived to the card as log/Archive/Ssh/<dates>/SSH.log.

When the file reaches this size it is archived to the card; with no card the newest ten lines are kept.

Also print to the terminal

The same lines appear on the UART console. Faults of the server itself (a port that cannot be bound) always go to Errors.log, never here.
